# 📊 Data Professional Survey Analysis (Power BI)

## 📌 Project Summary

Analyzed survey data from data professionals to understand salary trends, skill preferences, and career satisfaction across different roles and countries.

---

## ❓ Business Questions

* Which data roles have the highest salaries?
* What programming languages are most preferred?
* How satisfied are professionals with salary and work-life balance?
* How difficult is it to break into the data field?
* How do responses vary by country?

---

## 📂 Dataset

* Source: Data Professional Survey dataset
* Records: 600+ survey responses
* Features include:

  * Job Title
  * Salary
  * Country
  * Programming Language
  * Work-Life Balance Rating
  * Salary Satisfaction
  * Difficulty to Enter Field

---

## 🧹 Data Cleaning (Power Query)

* Removed null and inconsistent values
* Standardized job titles
* Cleaned categorical fields (e.g., country names, roles)

---

## 📊 Dashboard & Analysis

Built an interactive Power BI dashboard including:

* Salary comparison by job role
* Country-wise distribution of respondents
* Programming language popularity
* Work-life balance and salary satisfaction (gauges)
* Difficulty level of entering the data field

---

## 🔍 Key Insights

* Data Scientists earn the highest average salaries
* Python is the most commonly used programming language
* Majority of respondents report moderate difficulty entering the field
* Work-life balance ratings are higher than salary satisfaction
* Survey responses are globally distributed
